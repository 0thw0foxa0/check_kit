# Приложение "check_kit"

Это консольное приложение на C++, которое определяет содержатся ли наборы из файла kit.txt в файле document.txt. 
Приложение использует CMake для сборки и поддерживает платформы Windows и Linux.


### Пример использования
Запустите программу  `./check_kit`:
- Вывод при стандартных значениях kit и document

  - Набор содержится в документе.
  - Состав набора
  - Поз.   Кол-во    Каталог
  - 1      1         C
  - 2      2         B
  - 4      2         A
    

- Если document.txt лежит не в корневой папке и сборка происходит на windows:

  - Не удалось открыть файл: ../../document.txt

## Требования
- **Компилятор C++**: g++ (Linux) или MSVC/MinGW (Windows)
- **CMake**: Версия 3.10 или выше


## Установка
**Клонируйте репозиторий**:
  - git clone https://github.com/0thw0foxa0/check_kit.git
  - cd check_kit


### Сборка и запуск
## Linux
Запустите скрипт сборки:
- chmod +x build.sh
- ./build.sh

Запустите программу:
- cd build
- ./check_kit

## Windows
Запустите скрипт сборки:
- build.bat
- cd build\Debug

Запустите программу:
- check_kit
